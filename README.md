# AutoVision: Used Car Analytics Dashboard

An interactive and professional **Data Analytics Dashboard** built using **Python, Streamlit, Pandas, and Plotly**. This project analyzes a used car dataset to uncover valuable market insights, pricing trends, brand performance, and vehicle characteristics through interactive visualizations.

The dashboard is designed to demonstrate practical data analytics skills, including data cleaning, exploratory data analysis (EDA), business intelligence reporting, and dashboard development. It is suitable for showcasing on GitHub and as a portfolio project for Data Analyst roles.


# Project Objectives

- Analyze the used car market using real-world data.
- Identify pricing patterns across brands and locations.
- Compare vehicle specifications such as mileage, engine size, and power.
- Explore market trends based on fuel type, transmission, and manufacturing year.
- Present insights through an interactive Streamlit dashboard.


# Features

- Interactive dashboard with Streamlit
- Plotly visualizations
- Exploratory Data Analysis (EDA)
- Brand-wise vehicle analysis
- Price distribution and comparison
- Fuel type and transmission analysis
- Manufacturing year trends
- Location-based insights
- Business recommendations
- Fast data loading with Streamlit caching

# Dataset Information

The dataset contains information about used cars, including:

- Brand
- Model
- Manufacturing Year
- Price
- Fuel Type
- Transmission
- Mileage
- Engine Capacity
- Power
- Location
- Owner Type
- Seats
- Doors

This information enables comprehensive market analysis and supports data-driven decision-making


Navigate to the project folder:

```bash
cd Used-Car-Analytics
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
